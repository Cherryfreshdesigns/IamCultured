# IamCultured

List of scripts and CSS overwrites for I am Cultured (iamcultured.org)

## Subscribe Modal Button

This repository contains a complete implementation of a modal button that displays an embedded Constant Contact subscription form.

### Files

- **modal-button.html** - HTML structure for the button and modal
- **modal-styles.css** - CSS styling for the modal and button
- **modal-script.js** - JavaScript functionality for modal interactions
- **squarespace-implementation.html** - All-in-one file for easy Squarespace integration
- **demo.html** - Demo page to test the modal locally
- **IMPLEMENTATION-GUIDE.md** - Comprehensive implementation guide

### Quick Start

For Squarespace implementation, see [IMPLEMENTATION-GUIDE.md](IMPLEMENTATION-GUIDE.md) for detailed instructions.

### Features

- ✅ Responsive modal with embedded Constant Contact form
- ✅ Clean, modern design with animations
- ✅ Multiple ways to close (X button, outside click, Escape key)
- ✅ Prevents body scroll when modal is open
- ✅ Attempts to hide Constant Contact footer and image_container header
- ✅ Form submission works as expected

### Testing

Open `demo.html` in a browser to test the modal functionality locally.
