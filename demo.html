I am Cultured Newsletter Subscription

Click the button below to open the subscription modal:

This modal contains the embedded Constant Contact form. The footer and image container header are hidden using CSS.

How it works:

  • Click the button - Modal opens with the embedded Constant Contact form
  • Fill out the form - Complete the subscription form fields
  • Submit - Form submission works as expected for Constant Contact
  • Close the modal - Click the X, click outside the modal, or press Escape

Features:

  • Responsive design (works on all devices)
  • Smooth animations (fade in and slide down)
  • Multiple ways to close the modal
  • Prevents body scroll when modal is open
  • Attempts to hide Constant Contact footer and image_container header
  • Accessible keyboard navigation (Escape to close)

Implementation Notes:

For Squarespace implementation, you can either:

  • Use the all-in-one file: squarespace-implementation.html
  • Or add files separately using Code Injection (see IMPLEMENTATION-GUIDE.md)

Cross-Origin Note:

Due to browser security policies (CORS), JavaScript cannot directly modify content inside the Constant Contact iframe. The CSS injection attempts to hide the footer and image_container, but this may not work due to cross-origin restrictions. If these elements are still visible, you may need to:

  • Contact Constant Contact support for a custom embed without these elements
  • Modify the form in the Constant Contact form builder to remove them
